Sobre

O Jardim é um projeto fictício para mostrar como usar css basico. Aqui usamos seletores de elemento (h1, p, table), classe (.card) e id (#header, #main).

Exemplos de seletores usados

Elemento: estilizamos h1, p e table usando o seletor de elemento.

Classe: a classe .card cria cartões com fundo e borda;

ID: o id #header define a cor do cabeçalho e #main-table identifica a tabela principal.
